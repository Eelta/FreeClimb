# Mixamo animation attribution and terms

FreeClimb uses animation data from 27 Adobe Mixamo animations, retargeted for
its Skyrim climbing system. The runtime package includes the converted HKX
clips and supporting metadata as components of this game add-on.

Mixamo animation content remains subject to Adobe's terms. FreeClimb's GPL-3.0-only
license covers its own source code and does not relicense the animation data.
Original FBX files, character meshes, production projects and intermediate
poses are excluded from the release archives. The source archive contains
code and documentation rather than animation data.

Adobe's official FAQ lists games among the permitted uses. The applicable
Mixamo terms govern use of the content. The community licensing FAQ is a
supplementary explanation, not an independent contractual grant. The runtime
animation components must not be repackaged as a standalone animation library,
stock asset or template.

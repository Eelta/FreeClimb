# Threepeat Week 4 animation attribution and terms

Animation author: **Threepeat Games**. FreeClimb uses retargeted portions of
BracedIdle, BracedJumpLeftV5, BracedJumpRight and BracedIdleMantleV7final as
components of its Skyrim climbing system.

## Published use statement

The author's [Week 4 release post](https://www.reddit.com/r/unrealengine/comments/1fngonw/im_4_weeks_into_releasing_free_game_animations/)
states: “These are free as in freedom for commercial use in your projects!”
The accompanying [author demonstration](https://www.youtube.com/watch?v=K2FFxttPCmo)
identifies the animation set.

This published project-use statement is the documented basis for adapting the
animations for FreeClimb. It does not identify a standard CC0 or MIT license
or establish permission to redistribute the original asset pack independently.
This notice does not substitute for any additional terms attached to the
original asset distribution. FreeClimb's GPL-3.0-only source-code license does not
relicense these animations.

## Distribution scope

The runtime package includes converted HKX clips and supporting metadata
needed by FreeClimb. Original FBX files, UE/Manny skeleton files, character
meshes and Threepeat animation tools are excluded from the release archives.
The source archive excludes sampled poses and runtime animation data.

# FreeClimb 动作制作助手

[English](README.md) | 简体中文

需要在一个窗口里导入、预览和调整 HKX，请使用[动作工具](../converter/README.zh-CN.md)。下方配置助手是可选工具，不是该流程的必需步骤。

为已适配 FreeClimb 的 HKX 制作单动作覆盖包。可以保留原接触曲线，也可以用“哪只手脚、何时开始支撑、何时松开”生成曲线。

## 启动

需要 Windows x64、Python 3.10 或更新版本，以及 Python 自带的 Tkinter（安装 Python 时勾选 Tcl/Tk）。原生校验组件还需要 Microsoft Visual C++ 2015–2022 x64 运行库。无需安装第三方 Python 包，也不需要 Visual Studio。

解压完整源码包，双击本目录的 `Start.cmd`。它优先使用 `py -3`，其次使用 `python`。原生检查组件应位于 `bin/FreeClimbAuthoring.exe`；缺少组件时必须补齐，工具不会跳过检查导出。

## 制作一个覆盖包

1. 选择完整默认动作包的 `pack.json`，然后选择要替换的动作槽，例如 `up`。
2. 选择已适配的 HKX。检查结果会显示时长、帧数和轨道数；这里只证明文件可读取，后续还会检查整包。
3. 选择保留模板接触，或逐条添加四肢支撑区间。可选的 `stride`、`height`、`travel X/Y/Z` 留空即保留原值。
4. 选择基础包目录以外的 ZIP 位置，点击“校验并导出 MO2 覆盖包”。校验通过才写入 ZIP；失败不替换已有 ZIP。

ZIP 包含一个 HKX 和配套动作 JSON，路径从 `meshes/actors/character/animations/FreeClimb/` 开始。墙跑和情境侧跃仅导出当前方向，包含自己的过渡和所需参考。左右包可以一起安装，互不覆盖。旧 `contextHop` 共享覆盖包需用新版动作工具重新导出。安装到 MO2 的完整 FreeClimb 之后，保持基础包启用；离墙后安全重载，检查进入、移动、停止、切换和退出。

## 怎样标记接触

时间单位为秒，必须位于新 HKX 时长内。区间外的接触权重为 `0`，表示松开；区间内部最高为 `1`，表示请求支撑。

例如左手从 `0.20` 秒开始接触，到 `0.90` 秒松开，过渡设为 `0.05` 秒：`0.20–0.25` 渐入，`0.25–0.85` 保持支撑，`0.85–0.90` 渐出。过渡不得超过区间长度的一半。设为 `0` 时为直接切换，通常不如短暂过渡自然。相同肢体的重叠区间取最大权重；没有标记的肢体始终为 `0`。

工具按新 HKX 的实际解码帧数生成四列曲线，最多 1201 行。每个区间至少要覆盖一个正权重采样；如果源动画帧数过少、区间太窄或过渡占满后没有有效采样，工具会拒绝导出，需增加源采样或调整标记。工具不自动判断手脚何时贴墙，标记必须由作者结合动画完成。

## 特殊动作与高级配置

每个情境侧跃都保留自己的内部 `contextHang` 准备和收尾，手脚位置仅标定当前方向。基础片段中，`contextHopLeft/Right` 的 `path`、`sourceHands`、`targetHands`、`verticalBlend`，以及 `contextMantle` 的 `unplant`、`replant`、`releaseHands`、`replantSamplePhase`，需要和动画匹配。导入完整动作时，动作工具会自动生成配置，无需另外替换辅助片段。

这些字段默认完整保留，并在“高级配置与特殊动作”页展示。需要修改时勾选高级 JSON；不能改变 `slot` 或 `file`。基本参数输入会覆盖对应 JSON 字段，手工接触模式会覆盖 `contacts`。所有高级修改同样必须通过完整原生校验。仅修改四肢接触标记不会自动改动专用抓放窗口或路径。

## 范围与文件安全

- 工具不把任意 FBX、其它游戏动作或任意 Skyrim HKX 自动变成 FreeClimb 动作。骨架重定向、局部轴和动作质量仍需在动画软件中处理。
- 支持原生检查组件接受的 Skyrim SE 64 位 Havok 2010.2 interleaved 和部分 spline 布局。它不新增动作槽或触发方式，也不改变角色移动和碰撞规则。
- 检查成功不等于视觉效果完美。仍需游戏内查看手腕、肘部、手脚接触以及动作衔接。

更多动作参数见 [动作替换教程](../../docs/ANIMATION-DIY.zh-CN.md)。
